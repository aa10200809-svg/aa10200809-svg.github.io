10. docusaurus裡特有注意事項​

info

1.單一標籤要加斜線 /​

例如：換行 傳統寫法 <br>

Docusaurus寫法 <br/>

每一個標籤都必須有結尾，尾巴一定要加上 /


2.內聯樣式 兩層大括號 {{ }}​

例如：給文字加顏色或調大小

傳統寫法 <span style="color: red; font-size: 16px;">紅色文字</span>

Docusaurus寫法 <span style={{ color: 'red', fontSize: '16px' }}>紅色文字</span>

要用兩層大括號 {{ }}


3.記得空行​

列表前、HTML 標籤包覆 Markdown 時、提示區塊內部、段落換行等。記得「前後各空一行」
