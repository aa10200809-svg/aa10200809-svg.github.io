# AI Agent Instructions

This is a Docusaurus v3 personal website repository.

## Purpose
- Static site with docs and blog content.
- Personal GitHub Pages deployment configured in `docusaurus.config.js`.

## Key files
- `package.json` - install and run scripts.
- `docusaurus.config.js` - site configuration, navbar, footer, locale, deployment settings.
- `sidebars.js` - autogenerated docs sidebar configuration.
- `src/pages/index.js` - home page component.
- `src/css/custom.css` - custom styles.
- `docs/` - primary docs content for the docs sidebar.
- `blog/` - blog posts, including new daily posts.
- `新分頁_docs/` - custom docs plugin content exposed at `/music`.
- `關於我/` - custom docs plugin content exposed at `/about`.

## Common commands
- `npm install` - install dependencies.
- `npm run start` - run local development server.
- `npm run build` - create production build.
- `npm run deploy` - deploy to GitHub Pages.
- `npm run serve` - serve the generated build locally.

## Development notes
- Do not edit generated output in `build/`.
- Do not edit `node_modules/`.
- The site expects Node.js >= 20.
- `onBrokenLinks` is set to `ignore` in config, so check links manually when editing docs or navigation.
- The site uses Chinese folder names for custom docs content; preserve UTF-8 filenames and existing route structure.

## What to change
- Update docs content in `docs/`, `blog/`, `新分頁_docs/`, or `關於我/`.
- Update navigation or core site options in `docusaurus.config.js`.
- Update styling in `src/css/custom.css`.
- Update React pages/components in `src/pages/` and `src/components/`.

## What not to change
- `build/` output files.
- `package-lock.json` unless dependency changes are required.
- Generated docs artifacts.

## Useful guidance for AI
- Prefer editing source markdown and JS config files.
- Keep the GitHub Pages deployment settings intact: `url`, `baseUrl`, `organizationName`, `projectName`.
- Preserve existing Chinese path semantics for `/music` and `/about` sections.
- If asked to improve content, maintain the personal site’s existing tone and navigation structure.
