# 限量樂譜公開

這裡會存放我改編的流行音樂
敬請期待！！
:::tip[事先聲明]
以下樂譜是我親自打的，有些地方沒有寫得很詳細，這畢竟是流行音樂，和弦想怎麼配、怎麼改隨便你，也歡迎各位依據自己的喜好自由彈奏或修改。

另外，大家可能會覺得譜怎麼都這麼短，只有副歌部分，我想說這是為了配合**現代人愛滑短影音這種習慣**，彈這些流行樂，就是為了炫耀炫耀，拿去哀居限動發一發，你彈太長不會有人有耐心聽完，再來就是**打譜真的很麻煩**～請大家見諒
:::
